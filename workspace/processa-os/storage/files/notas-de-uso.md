# Notas de uso

- Login aceita qualquer combinacao de usuario + senha (prototipo).
- Chat Anvil conversa de verdade com o agente em D:/anvil.
- Notas sao persistidas em storage/data/notes-<usuario>.json.
- Arquivos lista esta propria pasta.
- Notificacoes vem via SSE — chega uma quando o chat termina e quando uma nota e criada.
