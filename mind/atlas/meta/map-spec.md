# Map — `atlas/maps/`

Notas curadas que agrupam outras notas em torno de um tema, contexto, projeto ou sistema. Comentário escrito à mão entre os links é o ponto. Toda higher-order note do projeto vive aqui — MOCs, Hubs, Index Notes.

## Key Points

- Vive em `mind/atlas/maps/`.
- É um [[MOC]] por definição neste projeto.
- Emerge da necessidade — nunca crie um map preemptivamente. Veja [[squeeze-point]] e [[threshold]].
- Mínimo frontmatter; corpo é prosa intercalada com `[[wikilinks]]`.

## Details

Frontmatter mínima:

```yaml
---
title: "Map: Theme or Project Name"
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

Corpo: prosa comentário entre wikilinks. A **posição** dos links importa — proximidade é declaração. Veja [[proximity]].

Quando criar um map:
- Um projeto emite múltiplas notas e precisa de um hub que descreva como elas se relacionam.
- Um tema acumula artigos suficientes que navegar sem ponto curado vira fadiga.
- Um sistema precisa de auto-descrição em forma LYT.

Espere o [[squeeze-point]] ou no mínimo ~3–4 notas relacionadas antes de criar. Quando criado, segue as regras de [[threshold]] e [[moc-growth]] como qualquer outro MOC.
