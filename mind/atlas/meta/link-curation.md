# Art of Link Curation

Link com intenção. Cada link é uma afirmação: "estas duas notas se relacionam de um jeito que importa." Se você não consegue explicar por que um link existe, não o crie.

## Key Points

- **Link Dilution** é o oposto: conectar tudo a tudo. Diluiu o grafo, perdeu o significado.
- Cada aresta é curatorial — uma escolha, não um reflexo.
- Antes de adicionar um link, articule a relação. Se a articulação falha, o link não merece existir.
- A meta-regra: mais links **curados** > mais links totais.

## Details

A regra opera em tensão com [[home-reachable]]: aquela exige um piso (toda nota tem pelo menos uma aresta de entrada em cadeia válida); esta exige um teto (não adicione arestas além das significativas). O agente vive entre os dois.

Esta arte distingue uma base LYT viva de um wiki cheio de "ver também" automáticos.
