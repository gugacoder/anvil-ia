# Progressive Ideation

O esforço de pensar deve **compor com o tempo**. Toda sessão deve deixar a base de conhecimento ligeiramente mais rica — novos conceitos extraídos, novos links desenhados, novos MOCs refinados.

## Key Points

- Cada sessão acrescenta — não reinventa.
- O oposto: começar do zero a cada sessão, deixando o trabalho anterior virar fóssil.
- Em prática, é o efeito composto de muitas pequenas síntese ao longo do tempo.

## Details

Progressive ideation é por que [[evergreen]] importa: notas que crescem com revisitas são o substrato em que a composição acontece. Sem evergreens, cada sessão começa do nada. Com evergreens, cada sessão começa do que a anterior deixou.

Operacionalmente: ao fim de uma sessão, pergunte "o que ficou mais rico aqui?" — um conceito acrescentado, um link novo, um MOC reorganizado. Se a resposta for "nada", a sessão foi note-taking, não note-making.
