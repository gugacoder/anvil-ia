# Effort — semântica deste projeto vs LYT estrito

A definição estrita de **Effort** no glossário do LYT (Milo) é mais estreita do que o uso desta base. Esta divergência é deliberada.

## Key Points

- **Estrito LYT**: "uma ideia fluida, sem deadline, sobre a qual você sente o spark de querer compartilhar."
- **Neste projeto**: `mind/effort/` é mais amplo — qualquer trabalho em curso que vai eventualmente graduar para Atlas, incluindo drafts esperando aprovação, fases de pesquisa, refinamento interativo de Q&A, e outros.

## Details

Use `mind/effort/` para qualquer trabalho multi-passo que não cabe numa única sessão e vai eventualmente produzir uma ou mais notas que vão para `atlas/concepts/`, `atlas/connections/`, `atlas/qa/`, `atlas/works/` ou `atlas/maps/`. Não se preocupe se a frente específica se encaixa na definição estrita do Milo.

A divergência mantém o espírito (espaço fluido para pensamento em curso) sem amarras (sem requisito de "spark de compartilhar"). Veja [[effort]] (sub-MOC) para o ciclo de vida e [[effort-graduation]] para destinos.
