# Heterarchy

Modo não-hierárquico de organização onde elementos podem ser agrupados de múltiplas formas simultaneamente. MOCs realizam heterarquia: a mesma nota-conceito pode aparecer em vários maps sem ser "propriedade" de nenhum.

## Key Points

- Diferente de hierarquia: não há "pasta única" de um conceito.
- Uma nota é heterárquica quando pode ser membro de múltiplos contextos sem perder identidade em nenhum.
- Nunca force uma nota a pertencer a exatamente um contexto.

## Details

A heterarquia é o que distingue redes de árvores. Uma árvore tem um caminho único da raiz até cada folha; uma rede admite múltiplos caminhos. O grafo de [[LYT]] é uma rede precisamente porque os MOCs são heterárquicos.

Operacionalmente: ao criar um concept article, pergunte "em quais contextos esta ideia importa?" — se houver mais de um, o conceito é multi-MOC. Cada MOC referencia o conceito a partir de uma perspectiva diferente.
