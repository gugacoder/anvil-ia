# Refraction Thinking

Pensar sobre UMA coisa através das lentes de OUTRA coisa. É ferramenta para alargar perspectiva, não para decidir ação.

## Key Points

- Pergunta-base: "como é o conceito X visto através do conceito Y?"
- A resposta é frequentemente uma connection article. Veja [[connection-spec]].
- Não confundir com decisão: refraction explora, não conclui.

## Details

Refraction é o método que produz conexões não-óbvias entre conceitos que vivem em domínios diferentes. Quando você nota que dois conceitos se iluminam mutuamente — um sob a luz do outro —, isso é refraction. O traço dela vira uma connection article em `atlas/connections/`.

Operacionalmente, refraction é a ferramenta principal da fase **Relate** do [[ARC]]: você não está adicionando material novo, está olhando o material existente sob novos ângulos.
