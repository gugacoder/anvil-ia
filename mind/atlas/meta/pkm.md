# PKM — Personal Knowledge Management

Do glossário do LYT Kit:

> PKM é "o processo de indivíduos fazendo, usando, organizando, conectando, combinando, colaborando e criando com suas notas pessoais."

Mais informalmente: PKM é **o processo de fazer sentido do mundo**. Não é note-taking; é note-making. Não é estocagem; é síntese.

## Key Points

- **Note-takers** — coletores passivos. Clipam, marcam, salvam pra depois. Suas notas viram cemitério.
- **Note-makers** — sintetizadores ativos. Reescrevem com palavras próprias, conectam ideias, deixam as notas crescerem como parceira de pensamento.
- O agente deve operar como note-maker: arquivos em [[inbox]] são matéria-prima; as notas que ele produz são o valor.

## Details

A distinção é estrutural, não estilística. Salvar o original e nunca mais voltar é cemitério. Reescrever com palavras próprias, linkar para outros conceitos, refinar com o tempo — isso é PKM viva.

O binário em [[x-files]] preserva proveniência; a nota em `atlas/concepts/` é o que carrega significado. Veja [[evergreen]] para o estado maduro de uma nota.
