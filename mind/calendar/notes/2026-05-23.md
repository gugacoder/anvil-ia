**Key Exchanges:**

- Bug `MobileDock setState during render`: descoberto que `togglePin` chamava `dispatchEvent` síncrono dentro do updater do `setDockSlugs`, o listener no MobileDock disparava setState durante o render do MobileAppDrawer. Fix: side-effects (localStorage, haptic, dispatch) fora do updater, persistência via useEffect com flag `loaded` pra não sobrescrever no mount inicial.
- Manifest 404 "Line 1 Syntax error": `href="/so/manifest.webmanifest"` no index.html + Vite `base: /so/` prefixou pra `/so/so/manifest.webmanifest` → SPA fallback retornou HTML → parser de manifest tentou JSON → erro. Fix: paths relativos no index.html (`href="manifest.webmanifest"`).
- CSS var nested resolution: `--background: oklch(... var(--accent-h))` declarada em `:root` não re-resolve `--accent-h` quando descendente (body) sobrescreve. Substituição da var aninhada fica congelada no escopo da declaração. Workaround: aplicar a classe de override (`theme-brasa`, etc) no MESMO elemento onde as vars derivadas vivem — no caso `<html>`.

- Vocabulário: discutido `os|web` (curto) vs `windowed|workspace` (expressivo). Escolhido `windowed|workspace` em todo lugar (env, storage, TS) pra eliminar mapeamento e ter mesma palavra em todos os pontos.
- Env CSV format design: primeiro item = default, lista = available, 1 só = trava. Per-breakpoint (3 vars, não geral) porque cenários reais batem com per-break.

**Lessons Learned:**

- React updater de setState deve ser PURO. Side-effects dentro (dispatchEvent síncrono especialmente) causam re-render em outro componente durante o render atual, gerando warning "Cannot update a component while rendering a different component". Fix: persistência via useEffect.
- CSS variable resolution não é lazy completa: `var()` aninhada em `oklch()` é substituída no escopo onde a var pai foi DECLARADA, não onde é USADA. Mover overrides pra mesmo elemento das declarações resolve.
- Vite `base: /so/` re-prefixa hrefs absolutos no index.html → duplica path. Usar paths relativos (`href="manifest.webmanifest"` sem barra inicial) deixa Vite prefixar uma vez só.
- Misinterpretação de vocabulário PT-BR custou rodadas (`desktop` = "área de trabalho", não "modo desktop"). Confirmar significado antes de inferir paradigma.
- Redundância em SOUL gera conflito impossível de resolver depois (duas fontes de verdade pra mesma coisa). SOUL minimalista + wikilinks pra operacional resolve.
- Smith.md hoje é director-studio-specific (paths hardcoded). Pra atender múltiplos workspaces precisa ser generalizado OU criar smith dedicado por esforço.
- Bug bonito de "perfect"-but-broken: assumi muitas vezes que algo estava ok porque parecia OK no probe, sem verificar visualmente. Disciplina de testar do POV do usuário (ui-tester com chrome MCP) seria ter pego mais cedo.
