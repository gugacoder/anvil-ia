- Lógica: busca pipeline+stages no DB do AppBuilder via `GenericDAO.Get<Pipeline>(int.Parse(jBody.Value("ids")))`, monta script T-SQL com `CREATE schema pipeliner` + `CREATE TABLE` (idempotente) + INSERT/UPDATE em `TBpipeline`/`TBstage`, executa em `userConfigRepository.GetUserConnection()`.
- **O DB destino é determinado pelo usuário Windows logado** — `appbuilder.TBconfiguracao_usuario` mapeia o user pra uma connection string. Pra "deploy em base interna de teste" o user dev tem connection apontando pro teste; pra "pacote cliente", aponta pro cliente.

Restrição do usuário (princípio): **não cadastrar via INSERT direto no DB**. Mexer na base macula as regras de negócio que o time dev mantém via AppBuilder. Caminho oficial é AppBuilder UI ou API.
