**Lessons Learned:**

- **Tree-shake com `import.meta.env.DEV` exige cuidado em 2 pontos**: (1) o import estático precisa virar `lazy()` + condicional (`null` em prod), (2) a registration na route tree precisa também ser condicional. Padrão que funciona em Vite/Rollup: `const X = import.meta.env.DEV ? lazy(() => import('./x')) : null` + `{...(X ? [route] : [])}`. Verificação obrigatória: `grep` no bundle final.
- **TanStack Router default error component vaza inglês cru** — precisa de `defaultErrorComponent` no `router` E `errorComponent` no `rootRoute` pra cobrir tanto erros pré-mount quanto erros em rotas filhas.
- **`useEffect` deps array nem sempre é o problema** quando hook não reage a mudança de prop. O bug pode estar no **body** do effect (early-return guard) que ignora a re-execução. Diagnose: verificar se o effect EXECUTA mas sai cedo, vs se o effect NEM EXECUTA. Diferentes problemas, diferentes fixes.
