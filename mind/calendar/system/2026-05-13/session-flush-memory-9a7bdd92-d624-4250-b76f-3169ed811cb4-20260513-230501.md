**Inteiro**

Utilizando o atributo `Type`, com o valor: **Int** ou **Integer**, o valor da tag será convertido para inteiro.

Exemplo:

```xml
<root>
    <id type="integer">1</id>
</root>
```

```json
{
  "id": 1
}
```

**Decimal**

Utilizando o atributo `Type`, com o valor: **Decimal** ou **Double**, o valor da tag será convertido para decimal.

Exemplo:

```xml
<root>
    <id type="decimal">1.987</id>
</root>
```

```json
{
  "id": 1.987
}
```

> *Obs: a quantidade de casas decimais será preservada após a conversão.*

**Booleano**

Utilizando o atributo `Type`, com o valor: **Bool** ou **Boolean**, o valor da tag será convertido para booleano.

Exemplo:

```xml
<root>
    <id type="bool">false</id>
</root>
```

```json
{
  "id": false
}
```

## Arrays

Para definir que uma tag deve ser convertida em _array_, é necessário que seu primeiro filho possua o atributo `Array` com valor **true**.

Exemplo:

```xml
<root>
  <row array="true">
    <id>1</id>
    <nome>Fulano</nome>
  </row>
  <row>
    <id>2</id>
    <nome>Ciclano</nome>
  </row>
</root>
```

```json
[
  {
    "id": "1",
    "nome": "Fulano"
  },
  {
    "id": "2",
    "nome": "Ciclano"
  }
]
```

**Omitir**

No exemplo anterior, a tag raíz foi automaticamente omitida do _array_ gerado.

Caso seja necessário que ela seja considerada durante a conversão, basta utilizar o atributo `Omitir` com valor **false**.

Exemplo:

```xml
<root>
  <row array="true" Omitir="false">
    <id>1</id>
    <nome>Fulano</nome>
  </row>
  <row>
    <id>2</id>
    <nome>Ciclano</nome>
  </row>
</root>
```

```json
{
  "row": [
    {
      "id": "1",
      "nome": "Fulano"
    },
    {
      "id": "2",
      "nome": "Ciclano"
    }
  ]
}
```

**Array de valores**

Caso seja necessária a geração de um _array_ simples de valores (e não de objetos), estes devem estar presentes diretamente como valores das tags filhas da raiz.

Exemplo:

```xml
<root>
  <row array="true">imagem1.png</row>
  <row>imagem2.png</row>
  <row>imagem3.png</row>
</root>
```

```json
[
  "imagem1.png",
  "imagem2.png",
  "imagem3.png"
]
```

A regra utilizada anteriormente para evitar a omissão da raíz também é suportada neste caso.

Exemplo:

```xml
<root>
  <row array="true" Omitir="false">imagem1.png</row>
  <row>imagem2.png</row>
  <row>imagem3.png</row>
</root>
```

```json
{
  "row": [
    "imagem1.png",
    "imagem2.png",
    "imagem3.png"
  ]
}
```

## Objetos aninhados

A geração de objetos aninhados segue a exata mesma lógica do padrão XML, não necessitando de nenhum atributo especial para este fim.

Exemplo:

```xml
<root>
  <path>
    <id>1</id>
    <details>
      <name>John Doe</name>
      <age>65</age>
    </details>
  </path>
</root>
```

```json
{
  "path": {
    "id": "1",
    "details": {
      "name": "John Doe",
      "age": "65"
    }
  }
}
```
